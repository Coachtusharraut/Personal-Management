# Eagle Structure — LifeOS

**One mission:** grow through the Sahyadri campaign and keep life and business actions aligned with your goals.

## Live app
https://coachtusharraut.com/life/

Active WordPress plugin: **Eagle Structure LifeOS v1.5.0**. The page remains password-protected; use the same page password on every device.

## One dashboard
A single scrollable Eagle dashboard brings together:
- A bottom-to-top Sahyadri mission route and progress stats.
- Partner Network with Personal PV and automatically calculated Group PV.
- My Missions with nested task/subtask trees and recursive progress.
- Life & Business Logbook in the top-right menu.

## Partner Network
The initial editable hierarchy is seeded from Tushar's whiteboard. Add/edit/remove any partner under any parent. Group PV sums Personal PV recursively, including Tushar's own Personal PV. Qualification percentage formulas are not assumed; Coach Tushar will supply them later.

## Recursive tasks and resources
Tasks can nest to any practical depth. Leaf actions are checkable; progress is calculated from completed descendant leaf actions. Each task node can store optional notes, a resource link and private PDF attachments (5 MB per PDF), accessible on any device through password-protected endpoints.

## Closed-loop guidance
Closed loop is the coaching process: notice when actions drift from the goal, correct the next action and return to the goal. It is not a separate record category.
