# Eagle Structure — LifeOS

**Live app:** https://coachtusharraut.com/life/  
**Current release:** Eagle Structure LifeOS v1.5.13  
**Canonical Git branch:** `main`

Eagle Structure LifeOS is a private, mobile-first dashboard for Sahyadri fort milestones, recursive tasks, archiving, LOS, potential partners, Personal Assets, the Life & Business logbook and daily growth.

## v1.5.13 — in-app YouTube viewing
- YouTube videos attached to task links now have an in-app **Full screen / Minimise** control.
- Expanding fills the app viewport; minimising returns the player to its original task position.
- The same iframe stays mounted when its size changes, preserving playback state.
- Enables inline playback and iframe fullscreen permission while keeping video viewing inside LifeOS.
- Updated asset and service-worker cache versions to v1.5.13.
