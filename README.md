# Eagle Structure — LifeOS

**Live app:** https://coachtusharraut.com/life/  
**Current release:** Eagle Structure LifeOS v1.5.5  
**Canonical Git branch:** `main`

This repository is the source of truth for the current LifeOS project. The previous Personal Management prototype remains recoverable in Git history.

## Current product

Eagle Structure LifeOS is a private dashboard for tasks and nested subtasks, a real LOS partner hierarchy/PV tracker, a separate potential-partner pipeline, a Personal Assets vault, in-app resources, the Life & Business logbook and a daily personal-growth tracker.

The live WordPress page remains password-protected.

## v1.5.5 highlights

- Restores the full Partner Network list on the dashboard, directly below the hero.
- Removes unused header shortcut icons and keeps the menu as the main navigation control.
- Compresses the mobile stats strip so the progress percentage fits inside its ring and XP, forts, steps, partners, GPV and PIN values sit side by side.
- Shortens the Sahyadri map for phone screens while keeping its winding fort route.
- Makes Add controls compact plus-only icons.
- Replaces prominent up/down arrows with compact drag handles for tasks, LOS partners and daily-growth tasks. Dropping onto a person/task changes its level; dropping above or below changes order.
- Adds a glowing, clickable daily-growth star with a score out of 10, editable tasks and unlimited nested subtasks.
- Seeds daily examples for affirmations (morning, afternoon, evening), exercise and 10-minute meditation.
- Stores each date's score and shows a monthly score history. The daily score is separate from ordinary task XP and LOS/PV totals.
