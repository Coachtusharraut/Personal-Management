# Eagle Structure — LifeOS

**Live app:** https://coachtusharraut.com/life/  
**Current release:** Eagle Structure LifeOS v1.5.12  
**Canonical Git branch:** `main`

Eagle Structure LifeOS is a private, mobile-first dashboard for Sahyadri fort milestones, recursive tasks, archiving, LOS, potential partners, Personal Assets, the Life & Business logbook and daily growth.

## v1.5.12
- Added a compact eye icon immediately to the left of the plus button in the dashboard's Partner Network section.
- Tapping the eye opens the full LOS / Partner Network hierarchy.
- The plus button remains unchanged and continues to add a partner.
- Added accessible label and title text for the eye control; the icon stays compact on mobile.
