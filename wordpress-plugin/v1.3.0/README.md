# Eagle Structure LifeOS — v1.3.0

**Live app:** https://coachtusharraut.com/life/

**Page ID:** 900135

## What changed

- The campaign map now derives from the active task list. One task = one fort marker.
- Add a task: a new map stop and total appear immediately.
- Remove a task: its map stop and total disappear immediately.
- Add/remove subtasks: step totals and task completion recalculate immediately.
- Complete a subtask: progress, XP, mission status and the eagle's next objective update immediately.
- Complete all subtasks in a mission: that fort is captured.
- Compact dashboard and low-text task cards.
- Animated eagle, Sahyadri mountain scene, fort guard and victory effects.
- Short victory chime and optional device vibration on task completion; respects reduced-motion preferences.

## Scope

Only the Level 1 task journey is included. People, teams, IBOs, activity logs, assistant, Eagle Council, Field Guide and other business screens remain removed.
