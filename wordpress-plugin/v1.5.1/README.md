# Eagle Structure LifeOS — v1.5.1

**Live app:** https://coachtusharraut.com/life/  
**Plugin:** Eagle Structure LifeOS v1.5.1

## Task resources
- Attach images, PDFs, audio, video and other file types to any nested task or subtask.
- 10 MB per file.
- Images, PDFs and supported audio/video formats preview inside LifeOS; other file types download.
- Existing YouTube links in the Resource link field embed as a player inside the expanded task. Supported formats: youtube.com/watch, youtu.be, /embed, /shorts and /live.

## Partner Network
- Each partner card shows Personal PV, recursive Group PV, PIN/Silver percentage, and branch people count.
- Branch count includes that partner and all people below them; Tushar's root total counts all downline partners.
- Qualification thresholds are calculated from Group PV:
  - 200 PV → PIN 1 · 3%
  - 600 PV → PIN 2 · 6%
  - 1,200 PV → PIN 3 · 9%
  - 2,400 PV → PIN 4 · 12%
  - 4,000 PV → PIN 5 · 15%
  - 7,000 PV → PIN 6 · 18%
  - 10,000 PV → Silver · 21%

## Visual network
The eye / View tree button opens a dedicated hierarchy page showing all branches. The tree updates from the same partner data, can be zoomed with +/−/Fit controls, and panned by dragging. Add/edit/remove is available directly from the visual tree.

## Preserved and migration
Existing missions, recursive task data, checkmarks, task notes, resource links, attachment references, partner IDs/PV values and Logbook entries remain in the shared page-password-protected WordPress record. Legacy task subtasks continue to normalize into the recursive children structure.
