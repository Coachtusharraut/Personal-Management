# Source change record — v1.5.11

## Changed files
- `assets/eagle.css`: explicitly use LifeOS's Inter/system sans-serif font stack for fort names and progress counts, while keeping the compact 8px desktop / 7px narrow-mobile sizes.
- `assets/eagle.js`: remove SVG `textLength` and `lengthAdjust="spacingAndGlyphs"` attributes so glyphs are not artificially stretched.
- `eagle-structure-lifeos.php`: bump plugin/runtime/service-worker cache version to 1.5.11.
- `README.md`: add v1.5.11 release note.

No badge geometry, fort positions, progress values, map sizing, partner data, tasks or other features changed.

## Source availability
The complete installable plugin source is in the versioned ZIP delivered with this release. This record does not imply that raw plugin source files are committed individually to GitHub.
