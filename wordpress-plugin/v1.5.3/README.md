## What changed

### Partner Network controls
- The Add leg control is now a compact plus-only button.
- Added a small people icon to open the Potential Partners manager.

### Separate potential-partner list
Every prospect can have a name, notes and one of three direct colour-coded follow-up states:
- **Green — Add to LOS:** candidate ready to be added to the actual partner hierarchy.
- **Yellow — Need to contact:** follow-up is still pending.
- **Red — Contacted and declined:** the person has said no.

The manager lets you add, edit, delete and change a prospect's status with one tap. Notes are editable for each person.

### Separate left rail in the full graph
The Partner Network graph now has a slim Potential rail at the far left. Each prospect appears as a small coloured name chip. Tapping a name opens its editor. The rail and hierarchy occupy separate layout columns; prospects are not inserted into the partner tree.

### Data integrity
- Prospects are stored in the same shared, password-protected LifeOS state and synchronise across devices.
- Existing partner records, branch relationships, PV totals, GPV calculations, PIN qualifications and downline counts remain separate and unchanged.
- Existing data is preserved when older local and shared states are merged.
