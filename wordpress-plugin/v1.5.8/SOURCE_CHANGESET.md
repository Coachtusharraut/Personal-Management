## Implementation
- Fort label width is calculated from the fort name, bounded to a mobile-safe maximum, and the SVG label text is compressed to fit within the visible rectangle.
- Label fill and text contrast adjusted for legibility.
- Numeric count badges removed from the top-right menu items.
- CSS truncation guards added for narrow menu labels.
- Plugin version and service-worker cache bumped to 1.5.8.
- No state schema changes.

## Source availability
The complete installable plugin source is contained in the v1.5.8 ZIP delivered with this release. This repository folder contains release notes, manifest and this change record, not the raw source files individually.
