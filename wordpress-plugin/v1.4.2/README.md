# Eagle Structure LifeOS — v1.4.2

**Live app:** https://coachtusharraut.com/life/  
**Plugin:** Eagle Structure LifeOS v1.4.2

## Changes
- Mobile banner uses the full eagle artwork instead of cropping it.
- Mobile map, cards, controls and modal fit the viewport.
- Logbook labels shortened; status is Active / Done, not separate open-loop and closed-loop categories.
- One eye button reveals the short meaning of closed-loop guidance: notice drift, adjust the next action, return to the goal.
- Record cards are compact by default; eye buttons reveal notes, outcomes and next actions.
- Kavita mission subtasks now have short labels with optional explanations behind eye buttons.

## Preserved
Existing missions, task/subtask checkmarks, Logbook entries and the main bright Eagle campaign layout.
